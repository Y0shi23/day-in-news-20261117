The world's news of Tuesday 17 November 2026 on one illustrated front page: 31 stories, from the Crimean Bridge strike, US–Iran clashes in the Gulf and the Quad summit in Manila to Nvidia's record quarter, measles in the Americas and Sudan's drone war, with a map that places each one. The page is drawn in `poster.html` (HTML, hand-drawn SVG and a small script for the flags, seat charts and map), rendered once to `entry.png` by `render.mjs`, and `main.ts` writes that image to the output folder.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts   # writes out/entry.png
node render.mjs                                       # redraws entry.png from poster.html (needs Chrome, Brave or Chromium)
```
